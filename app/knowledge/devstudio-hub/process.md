# DevStudio Hub Project Process

## Getting Started

Customers can start a project by contacting DevStudio Hub.

The initial discussion is used to understand:

- Business type
- Website requirements
- Number of pages
- Desired features
- Existing website
- Design preferences
- SEO requirements
- Timeline

## Project Process

The typical process is:

1. Customer contacts DevStudio Hub.
2. Project requirements are discussed.
3. A design or mockup is prepared.
4. The customer reviews the proposed design.
5. A 50% deposit is made.
6. Website development begins.
7. The customer receives two rounds of revisions.
8. The website is completed.
9. The website is launched.
10. The remaining 50% payment is made.

## Design Approval

The customer gets an opportunity to review the proposed design before development proceeds.

The goal is to ensure that the design direction is acceptable before the main implementation begins.

## Revisions

Projects include two rounds of revisions according to the selected service/package.

Additional work outside the agreed scope may require additional discussion and pricing.

## Timeline

New website projects typically take:

5–14 days.

Redesign projects can typically take:

3–7 days.

The actual timeline depends on project complexity, content availability, communication, revisions, and required functionality.

## Content

If the customer has website content, it can be used during the project.

If content is missing, the project requirements should be discussed before development begins.

## Hosting and Domain

Hosting and domain requirements can be discussed as part of the project.

The AI receptionist must not invent hosting or domain prices unless those prices are explicitly available in the knowledge base.
