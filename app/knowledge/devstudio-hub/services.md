# DevStudio Hub Services

## New Website

DevStudio Hub builds custom websites for businesses that need a new online presence.

A new website package can include:

- Website strategy
- Sitemap planning
- Custom design system
- 4–8 pages
- Responsive design
- On-page SEO
- Performance-focused implementation
- Revisions
- Website launch

Typical timeline:

5–14 days.

Starting price:

$500.

The final price depends on the project requirements, number of pages, features, and complexity.

## Website Redesign

DevStudio Hub can redesign an existing website to give it a more modern and professional appearance.

A redesign can include:

- Existing website review
- Fresh visual design
- Website rebuild
- 3–7 pages
- Content migration
- Responsive design
- Basic SEO

Premium redesign work can include full SEO.

Starting price:

$600.

The final price depends on the scope and complexity of the redesign.
